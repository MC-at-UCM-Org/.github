## Overview

Welcome! This is the official GitHub organization for the Minecraft at UC Merced club! Here you'll find source code for custom plugins and server mods, as well as config files and scripts for generating in-game tools. Feel free to get involved!

## 🙏 Want to Contribute?

We'd appreciate it! See our organization template's [CONTRIBUTING.md](https://github.com/MC-at-UCM-Org/Template/blob/main/CONTRIBUTING.md) to see our specific coding guidelines. If you're new to git/GitHub, coding, or working on a team, see [our organization-wide CONTRIBUTING.md](./CONTRIBUTING.md) to get an understanding of how to interpret contributor expectations.

## 🚨 Obligations and Code Security

As a general rule, don't break the law, don't break TOS/EULA, and don't write malware. It's a little confusing, but as long as you're acting in good faith, that's enough. We're all here to help, and that includes catching each others' mistakes.

Some common gotchas might be as follows:

**Copying [copyleft](https://en.wikipedia.org/wiki/Copyleft) (e.g., GPL, CDDL) code into a club project with a more permissive license (e.g., MIT, Apache).** "Free and Open Source" doesn't mean "no licensing restrictions." If you're doing your best, don't worry about it too much. That's why we have code review!

**Anything bypassing Microsoft/Mojang account auth.** We don't want to get the school in trouble for facilitating us pirating the game! So no facilitating cracked accounts. Though, allowing multiple "subaccounts" on on one free account seems to be allowed legally, by ToS, and by EULA, but most see it as a gray area.

**Redistributing Minecraft's Code and Assets.** While Mojang *did* [stop obfuscating Minecraft's code](https://www.minecraft.net/en-us/article/removing-obfuscation-in-java-edition), Minecraft is *still* closed-source, and its code and assets are copyrighted. Redistributing them is piracy and against the law. The game is (effectively) *source-available*, but neither [free software](https://www.gnu.org/philosophy/free-sw.en.html) nor [open source](https://opensource.com/resources/what-open-source).

More detailed directions are available in [SECURITY.md](./SECURITY.md)
